# AI NGO Intelligence — Professional Website v2

A refined, responsive, static, trilingual (English / Dari / Pashto) marketing website. Version 2 adds a more polished visual system, stronger responsive layouts, accessibility refinements, social-sharing metadata and improved navigation details.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design and RTL support
- `script.js` — language switcher, mobile navigation and inquiry email form

## Design updates in v2
- Refined navy / emerald visual identity and typography hierarchy.
- Improved hero dashboard presentation, spacing, cards, pricing and contact sections.
- Responsive mobile layout and RTL refinements for Dari and Pashto.
- Keyboard skip link, reduced-motion support and improved navigation accessibility.
- Social-sharing metadata and a lightweight inline favicon.

## Before publishing
1. Open `script.js` and replace `REPLACE_WITH_BUSINESS_EMAIL` with the real business email.
2. Review the Streamlit demo URL in `index.html`. Replace it if the live app URL changes.
3. Confirm all feature claims against the deployed application.
4. Confirm the public demo uses synthetic or properly de-identified sample data.
5. Add a real Privacy Notice and Terms of Use before accepting customer data.
6. Do not use this static contact form for sensitive data; it opens the visitor's email application and does not submit to a server.

## Run locally
Open `index.html` in a browser, or run a local static server from this folder:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Deploy
This is a static website and can be deployed to GitHub Pages, Netlify, Cloudflare Pages or any standard static host. No build step is required.

## Important product-scope note
The website intentionally avoids claims about enterprise security, multi-tenancy, SSO, automated integrations or certifications. Pricing is indicative and should be confirmed in a written proposal.
